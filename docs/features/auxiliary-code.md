# 辅助码

在输入状态下，输入以下命令切换对应直接辅助或间接辅助。切换后需**重新部署**。

| 命令 | 辅助码引导模式 |
| --- | --- |
| `/jjf` | 间接辅助 |
| `/zjf` | 直接辅助 |

## 直接辅助码 <Badge type="tip" text="仅 Pro" />

在双拼编码后直接追加辅助码。

重码处理：

- 当双拼 + 辅码与现有词组重码时（均为 4 码），优先显示词组。
- 在编码末尾追加 `/` 可强制聚拢辅助码，优先展示单字。
- 以大写输入任意一位辅助码，即可强制聚拢为单字。

::: info 示例

以「你」字为例：双拼编码为 `ni`，辅助码为 `re`。

可使用以下方式输入：

- 双拼 `ni` → `ni`。
- 双拼 `ni` + 首位辅助码 `r` → `nir`。
- 双拼 `ni` + 完整辅助码 `r` → `nire`。
- 双拼 `ni` + 完整辅助码 `re` + 强制聚拢 `/` → `nire/`。
- 双拼 `ni` + 完整辅助码首位大写 `Re` → `niRe`。
- 双拼 `ni` + 完整辅助码末位大写 `rE` → `nirE`。
- 双拼 `ni` + 完整辅助码大写 `RE` → `niRE`。

:::

## 间接辅助码 <Badge type="tip" text="仅 Pro" />

在双拼编码后输入引导符 `/` ，并追加辅助码。

::: info 示例

以「你」字为例：双拼编码为 `ni`，辅助码为 `re`。

可使用以下方式输入：

- 双拼 `ni` → `ni`。
- 双拼 `ni` + 引导符 `/` + 首位辅助码 `r` → `ni/r`。
- 双拼 `ni` + 引导符 `/` + 完整辅助码 `re` → `ni/re`。

:::

## 声调辅助筛选

输入单字拼音后，可输入以下代表音调的数字筛选读音声调：

- `7`：阴平（第一声）
- `8`：阳平（第二声）
- `9`：上声（第三声）
- `0`：去声（第四声）

声调数字后再次输入数字可修正声调。

::: info 示例

以「你」字为例：拼音编码为 `ni`；读音为 nǐ，声调为上声（第三声），对应的数字为 `9`。

可使用以下方式输入：

- 拼音 `ni` → `ni`。
- 拼音 `ni` + 声调数字 `9` → `ni9`。

:::

## 辅助码提示

### 拆分提示 <Badge type="tip" text="仅 Pro" />

在[方案选单](https://github.com/rime/home/wiki/UserGuide#%E4%BD%BF%E7%94%A8%E6%96%B9%E6%A1%88%E9%81%B8%E5%96%AE)中切换「拆分提示关」/「拆分提示开」选项，或在输入法窗口按下 `Ctrl` + `C`，可开启或关闭拆分提示。

开启后，将在单字候选的注释中显示该字的辅助码及对应的拆分方式。

### 辅助码提示 / 读音提示

在[方案选单](https://github.com/rime/home/wiki/UserGuide#%E4%BD%BF%E7%94%A8%E6%96%B9%E6%A1%88%E9%81%B8%E5%96%AE)中切换「提示关」/「辅助码提示」/「读音提示」选项，或在输入法窗口按下 `Ctrl` + `A`，可切换辅助码提示或读音提示。

<Badge>仅 Pro</Badge> 开启辅助码提示后，将在单字候选的注释中显示该字的辅助码。

开启读音提示后，将在单字候选的注释中显示该字的带音调全拼读音。

### 配置

```yaml
code_hint:
  # 显示辅助码注释的最大候选词长度。
  max_candidate_length: 1
```
