# 提示

## 错音错字提示

输入常见错误读音时，在候选注释中提示正确读音。

```yaml
correction_hint:
  # 显示错音错字注释。
  enabled: true
```

## 编码全拼展开

在[方案选单](https://github.com/rime/home/wiki/UserGuide#%E4%BD%BF%E7%94%A8%E6%96%B9%E6%A1%88%E9%81%B8%E5%96%AE)中切换「原编码 / 带声调全拼 / 无声调全拼」选项，或在输入法窗口按下 `Ctrl` + `S`，即可切换编码区显示模式。
